## Что готово в UI (2026-05-27)

### Primary entry-point

- **`/run`** — 4-step Wizard (Workload / Params / Target / Options).
  - Поддерживает 3 workload-типа: Scenario, Command (ErrandRun), Push.
  - Pre-fill из query-params: `?workload=` / `?service=` / `?incarnation=` /
    `?scenario=` / `?module=` / `?cmd=` / `?target_sids=` / `?target_coven=` /
    `?target_glob=` / `?target_regex=` / `?target_where=`.
  - При наличии target+filled-Step-2 — открывается сразу на Step 3.
  - DynamicInputBuilder fallback для модулей/scenario без input_schema.

### Bulk-run actions

- `/souls` multi-select → **«Run on N selected»** header button → Wizard pre-fill SIDs.
- `/souls` filtered (status/transport/coven/sid-search/soulprint-DSL) → **«Run on filtered»**
  → AND-merge всех фильтров → CEL where → Wizard pre-fill.
- `/incarnations/:name` Hosts tab → **«Run command on these hosts»** → Wizard
  pre-fill target_coven=<incarnation-name>.
- `/services/:name` Scenarios tab → **«Run this scenario»** → Wizard
  pre-fill scenario+service.

### DynamicInputBuilder

Новый компонент `src/components/input/DynamicInputBuilder.tsx`:
- Form mode: список key + type select + value (string/number/integer/boolean/json).
- Add/Delete per row.
- Toggle «Edit as raw JSON» с back-conversion.
- Live JSON preview.
- Validation: key required + uniqueness.
- Встроен в: Wizard Step 2 Scenario fallback, Command custom-module, Push input,
  IncarnationNewForm input fallback.

ScenarioInputFields для typed input_schema остаётся primary (per-field форма
из flat-map schema, генерируется автоматически).
